# Arquivos fonte da aplicação

Os quatro módulos Python iniciam o servidor local, coordenam a análise dos lotes e conectam o cliente oficial Google. Interface, prompts e verificações estão organizados nas pastas abaixo.

`iniciar.py` controla a inicialização, `app.py` coordena o fluxo e `google_login.py` conecta o Gemini. A página da entrega explica os módulos e seus contratos. `gestao.py` valida as baixas e calcula os totais semanais.
