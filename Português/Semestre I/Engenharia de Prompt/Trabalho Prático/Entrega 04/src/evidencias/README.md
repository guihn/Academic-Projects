## Verificação nativa Windows

O arquivo atual `validacao_portatil_windows.json` identifica o ZIP exato por SHA-256. No Windows 11 Enterprise LTSC, passaram as duas suítes de 103 testes; o portátil foi extraído em caminho com espaços e aberto pelo BAT, com o PATH da aplicação limitado a System32. Navegador, calendário, regressão de edição e resposta sem sessão foram aprovados. `testes_windows.txt` e `interface_portatil_windows.png` contêm os registros nativos. O Windows isolado não possuía sessão Google pessoal nem rede externa; as inferências reais foram verificadas separadamente nos testes de integração registrados.
