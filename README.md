## Organisation

Programming exercises follow the hierarchy **semester → course → assessment stage → course content → exercise**. The following example shows the path for the first exercise associated with Content I of Algorithms and Data Structures I:

| Level | Destination | Purpose |
| --- | --- | --- |
| Semester | [Semester&nbsp;I](English/Semester-I/README.md) | Groups courses by academic semester. |
| Course | [Algorithms and Data Structures I](English/Semester-I/Algorithms-and-Data-Structures-I/README.md) | Identifies the course by its full name. |
| Assessment stage | [Stage I](English/Semester-I/Algorithms-and-Data-Structures-I/Stage-I/README.md) | Groups activities within an assessment period. |
| Course content | [Content I](English/Semester-I/Algorithms-and-Data-Structures-I/Stage-I/Content-I/README.md) | Groups exercises by their source topic or unit, without including lecture materials. |
| Exercise | [Exercise I](English/Semester-I/Algorithms-and-Data-Structures-I/Stage-I/Content-I/Exercise-I/README.md) | Presents the problem statement and links to the solution. |
| Source code | [C01ex01.java](English/Semester-I/Algorithms-and-Data-Structures-I/Stage-I/Content-I/Exercise-I/src/C01ex01.java) | Contains the solution and preserves the course exercise identifier. |

Assessment stages correspond to the divisions between examinations. This hierarchy is adapted to the organisation of each course.
