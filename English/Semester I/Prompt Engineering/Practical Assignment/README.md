# Practical Assignment

The Semester I Prompt Engineering practical assignment applies prompt design and evaluation to a software project. Its development connects problem definition, structured model instructions, integration with the application and analysis of recorded results.

## Project context

ValidaMarket addresses expiration monitoring in supermarkets. Lot descriptions provide product, expiration date, quantity, section and storage conditions. The prototype turns this information into an expiration classification and an action recommendation, with field review and explicit human approval before a local alert is generated. The project supports loss prevention while keeping stock decisions under human control.

The prompt design combines extraction examples, structured JSON responses, conditional rules and chained calls. Python validates required fields and checks date calculations. Execution records support evaluation of both successful cases and extraction failures.

Weekly loss reporting uses actual declared writeoffs grouped by product and section. Customer service answers expiration questions and generates a local verification alert for an expired-on-shelf report. Numeric totals and date rules are calculated by Python; model responses remain available in the execution records.

## Available deliveries

The fourth delivery contains the working prototype, runtime Gemini integration, source code and test evidence. Its documentation covers execution, Google account authorization and the roles of the application modules.
