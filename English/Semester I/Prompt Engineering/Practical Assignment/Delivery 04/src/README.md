# Application source files

The four Python modules start the local server, coordinate lot analysis and connect the official Google client. Static assets, prompts and verification tools are grouped below.

`iniciar.py` handles startup, `app.py` coordinates the workflow and `google_login.py` connects Gemini. The delivery page explains the modules and their contracts. `gestao.py` validates writeoffs and calculates weekly totals.
